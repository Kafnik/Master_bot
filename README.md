**Master Bot** — игровой Telegram-бот на Python и **pyTelegramBotAPI** из сети **Openbot.Ai**. В зимнем сезоне доступны мини-игры, монеты, XP, снежки и снежинки, кейсы, коллекционные эмодзи, титулы и рынок между игроками. Доступ к некоторым функциям и права сотрудников связаны с общим **Openbot ID**.

> 📌 Этот README описывает текущую зимнюю сборку `test.py`, а не старый хэллоуинский релиз 1.6.1. Функции могут изменяться в процессе тестирования.

## ✨ Возможности

### 🎮 Зимние игры

В меню игры расположены **по две кнопки в ряд** (Inline и Reply). Открытые игры запускаются сразу; у закрытых стоит значок 🔒 и показывается причина ограничения. Сотрудники могут тестировать игры во время технических работ.

| Игра | Что нужно делать |
|---|---|
| ❌⭕ **Крестики-нолики** | Игра против ИИ на поле 3×3 с тремя сложностями: лёгкая, средняя и сложная |
| 🧊 **Ледяной лабиринт** | Пройти ледяные комнаты, выбирая безопасные проходы |
| 🎄 **Мастерская гирлянд** | Запомнить и повторить последовательность огоньков |
| 🐧 **Экспедиция пингвина** | Добраться до станции, расходуя силы и припасы |
| 🔔 **Морозный шифр** | Ответить на зимние загадки за ограниченное число ошибок |
| 🌌 **Полярное сияние** | Дополнительный зимний режим |
| 🚂 **Снежный экспресс** | Дополнительный зимний режим |
| 🏰 **Ледяная крепость** | Дополнительный зимний режим |

Включённость каждой игры определяется в `/features`. Три последних режима могут быть закрыты до официального открытия.

За успешные игры начисляются **монеты**, **XP** и **☃️ снежки**. В крестиках-ноликах награда зависит от сложности, а за ничью выдаётся 1 снежок. Для выхода из активной игры есть `/game_stop`.

### 💰 Экономика и валюты

| Валюта | Назначение |
|---|---|
| 💰 **Монеты** | Кейсы, титулы и покупки на рынке |
| ⭐ **XP** | Опыт игрока |
| ☃️ **Снежки** | Игровая награда; обмениваются на снежинки |
| ❄️ **Снежинки** | Зимние сундуки и новогодние титулы |
| ⭐ **Telegram Stars** | Отдельные покупки через Telegram |

**Обмен:** `10 ☃️ = 1 ❄️`. В разделе «☃️ Обмен снежков» доступны варианты 10, 50 и 100 снежков. Балансы отображаются в профиле и/или зимней лавке.

### 🎁 Зимняя лавка

В лавке предусмотрены отдельные кнопки:

- **🎁 Праздничные кейсы** — покупка и открытие кейсов.
- **👑 Титулы за монеты** — отдельный каталог титулов.
- **❄️ Титулы за снежинки** — новогодние коллекционные титулы.
- **☃️ Обмен снежков** — превращение игровых снежков в снежинки.
- **⭐ Валюта за Stars** — покупки за Telegram Stars.

Каталоги титулов показывают **по 4 позиции на странице**. Для листания используются «⬅️ Назад» и «Вперёд ➡️». Уже полученные титулы помечены ✅.

### 📦 Кейсы и зимний сундук

В игре есть восемь типов кейсов: 📦 Деревянный, 🥈 Серебряный, 🥇 Золотой, 💎 Алмазный, 🔥 Огненный, 🌌 Космический, 👑 Королевский и 🕳️ Кейс Пустоты.

Награды могут включать монеты, опыт, эмодзи, снежинки и **уникальный титул**, связанный с типом кейса. Титул из кейса сохраняется в коллекции «Мои титулы» — автоматически менять текущий титул игрока не нужно. При дубликате титула предусмотрена компенсация.

**❄️ Зимний сундук** — отдельная механика открытия за снежинки с наградами в виде эмодзи и компенсацией монетами за дубликаты.

### 👑 Новогодние титулы

Титулы можно получать из кейсов, покупать за монеты или обменивать на снежинки. Среди примеров:

- За монеты: «❄️ Повелитель снежинок», «👑 Снежный король», «⭐ Северная звезда».
- За снежинки: «🧝 Новогодний эльф», «🎅 Помощник Деда Мороза», «🕛 Хранитель курантов», «🌌 Легенда полярной зимы».
- Из кейсов: «🌟 Звезда снегопада», «💎 Ледяной кристалл», «👑 Корона мороза».

Все полученные варианты доступны в разделе **«🏆 Мои титулы»**.

### 🎒 Эмодзи и рынок

Игроки собирают эмодзи разных редкостей, могут надевать их в профиль, продавать боту и выставлять на **🏪 Зимнюю ярмарку**. На рынке есть листание лотов, отдельный список своих объявлений, покупка и снятие выставленных эмодзи. Продавцу может приходить уведомление о продаже, если уведомления включены.

### 📅 Календарь декабря и зимний релиз

- **31 день — 31 подарок** в декабре 2026 года.
- Пропущенные дни можно забрать позже после их открытия.
- Награды включают монеты, снежинки, золотые кейсы и титулы.
- **1 декабря 2026 года, 00:00 МСК** — дата открытия зимнего сезона, используемая заставкой ожидания.
- Сотрудники могут предварительно просматривать заставку, не теряя доступ к функциям бота.

### 🎮 Как пользоваться `/features`

1. Отправь `/features` в личные сообщения бота.
2. Нажми **🟢** рядом с игрой, которую нужно закрыть.
3. Выбери причину (технические работы, ошибки, обновление, разработка и т. д.). Бот сохранит причину, обновит панель и удалит временное сообщение выбора.
4. Чтобы снова открыть игру, нажми **🔒** рядом с ней.

Есть также кнопки **«Открыть все»**, **«Закрыть все»** и **«Обновить»**. Настройки хранятся в SQLite и сохраняются после перезапуска.

Ключи игр для текстовой команды и `/testgame`: `ttt`, `maze`, `lights`, `penguin`, `cipher`, `aurora`, `express`, `fortress`. Например, `/features maze on` открывает лабиринт. Для закрытия удобнее использовать панель — она позволяет выбрать причину.

### 🛠 Как пользоваться `/tech`

Панель `/tech` позволяет временно закрыть **весь бот** либо отдельные разделы: `games`, `cases`, `market`, `shop`, `calendar`, `rewards`, `economy`. При закрытии выбирается причина, которая отображается обычным игрокам. После выбора временное сообщение с причинами удаляется.

Текстовые примеры:

```text
/tech games off
/tech games on
/tech bot off
/tech bot on
/tech all off
/tech all on
```

`on` = открыть; `off` = закрыть. **owner, developer, admin и tester** сохраняют доступ к закрытым функциям для тестирования (если на них не наложена отдельная блокировка). Управление настройками доступно только ролям с необходимыми правами.

### 🚫 Блокировки

Действуют локальные и глобальные **BAN / HARD BAN**. Сообщения о блокировке содержат тип, причину, администратора и срок, если эти сведения доступны. `/ban_info` позволяет увидеть детали. Проверки банов сохраняются и для сотрудников: режим тестирования не отменяет наказания.

## 🚀 Установка и запуск

### Требования

- **Python 3.13+** (зимняя сборка также используется на Python 3.14).
- **pyTelegramBotAPI** (`telebot`).
- Библиотека **openbot_api** с поддержкой нужных методов Openbot ID.
- Файл **`master_winter_db.py`** рядом с основным скриптом.
- Доступ к SQLite (встроен в Python).

Пример установки зависимостей в виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
pip install pyTelegramBotAPI
```

Библиотеку `openbot_api` установи из используемой в проекте сборки. Она требуется для ролей, профилей и глобальных блокировок.

### Настройки

В начале `test.py` заданы переменные:

```python
TOKEN = "ТОКЕН_TELEGRAM_БОТА"
OPENBOT_API_KEY = "КЛЮЧ_OPENBOT_API"
DEVELOPER_CHAT_ID = 123456789
```

Это **пример**, не реальные значения. Настрой их перед запуском. Не публикуй настоящие ключи в открытом GitHub-репозитории.

### Запуск

```bash
python test.py
```

Если бот работает через systemd (например, тестовая служба):

```bash
sudo systemctl restart test-bot@test_room1.service
sudo journalctl -u test-bot@test_room1.service -n 50 --no-pager
```

Имя службы может отличаться в зависимости от окружения.

### Файлы и базы

```text
Master_bot/
├── test.py                   # основной скрипт текущей сборки
├── master_winter_db.py       # функции отдельной базы зимнего события
├── Master_bot.1.6.db         # основная база Master Bot
├── Master_winter_2026.db     # зимняя база: снежинки, кейсы, титулы
└── README.md                 # документация
```

В основной SQLite-базе хранятся пользователи, балансы, инвентарь, рынок, настройки, блокировки и состояние игр. Зимние награды и коллекции частично вынесены в отдельную базу. При обновлениях скрипта **не удаляй существующие `.db`-файлы** — иначе можно потерять данные игроков.

Логи ошибок записываются в `logs/master_bot.log` в общей папке уровнем выше скрипта.
