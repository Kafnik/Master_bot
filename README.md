## 📖 Описание

**Master Bot** — многофункциональный Telegram-бот с развитой игровой экосистемой, встроенным инвентарём, системой недвижимости, а также поддержкой локальных прав и единой системы глобальных аккаунтов **Openbot AI ID**.

---

## 🎮 Игровая система

В боте реализовано 6 различных игровых механик. Данные активных сессий фиксируются в БД (`active_games`), предотвращая сбои состояний.

| Игра | Описание | Механика и Награды |
| :--- | :--- | :--- |
| 💸 **Бизнесмен** | Экономический кликер с покупкой недвижимости. | **+10 💰** за клик. Покупка объектов: *Квартира* (500 💰, +50/мин), *Офис* (2000 💰, +250/мин). |
| 🔢 **Угадай число** | Логическая игра на угадывание числа от 1 до 10. | 5 попыток. Подсказки «МЕНЬШЕ» / «БОЛЬШЕ». Награда: **+50 💰**. |
| 🎡 **Летнее колесо** | Рулетка случайных праздничных событий. | Выпадает случайный ивент со случайным начислением или списанием 💰 и XP. |
| 🎲 **Кубик Судьбы** | Быстрая угадайка числа от 1 до 6. | 1 попытка. Награда при победе: **+100 💰** и **+25 XP**. |
| 🔐 **Взлом Кода** | Подбор 4-значного кода (от `0000` до `9999`). | 8 попыток. Подсказка выводит число совпавших цифр. Награда: **+150 💰** и **+50 XP**. |
| 💰 **Торговец** | Симулятор перепродажи товаров на базаре. | Покупка и продажа товаров (*Смартфон*, *Рубашка*, *Часы*, *Кроссовки*) с выгодой. |

## 🔑 Система прав и статусов (Локальная)

Определяет уровень доступа пользователя внутри **Master Bot** (`users.status`). Роли из списка `ALLOWED_ROLES` открывают доступ к административным командам.

| Локальный статус | Название в профиле | Доступ к админ-командам |
| :--- | :--- | :---: |
| `developer` | 🌐💠 Openbot.Ai | ✅ |
| `coder` | 🌐 Кодер | ✅ |
| `admin` | ⭐ Администратор | ✅ |
| `tester` | 🌐 Тестер | ✅ |
| `user` | 👤 Игрок | ❌ |
| `banned` | 🚫 Забаненный | ❌ (Полная блокировка бота) |

---

## 🌐 Система глобальных статусов (Openbot AI ID)

Глобальные статусы хранятся в общей базе `openbot_id.db` и синхронизируются между всеми ботами сети.

| Глобальный статус | Отображение | Описание |
| :--- | :--- | :--- |
| `developer` | 🌐💠 Openbot.Ai | Разработчик экосистемы Openbot.Ai |
| `coder` | 🌐 Кодер | Программист проекта |
| `admin` | ⭐ Администратор | Глобальный модератор/администратор |
| `user` | 👤 Игрок | Обычный пользователь |
| `frozen` | ❄️ Заморожен | Временная заморозка ID. Значок меняется на ❄️ |
| `banned` | ☠️ Забаненный | Полный бан во всей сети ботов. Значок меняется на 🚫 |

## 👤 Система аккаунтов и инвентаря

### 1. Локальный аккаунт (`Master_bot.1.5.db`)
* **Базовые параметры:** Уровень (`level`), опыт (`XP`), монеты (`coins`), причина бана (`ban_reason`).
* **Инвентарь и эмодзи:** Предметы хранятся в таблице `inventory`. Пользователи могут надевать кастомные эмодзи-значки (например, `🎈 kafnik`), которые автоматически отображаются рядом с именем в профиле.
* **Аукцион:** Возможность выставлять предметы на продажу через команду `/sell_emoji`.

### 2. Глобальный аккаунт (`Openbot AI ID`)
* **Авто-регистрация:** Создаётся автоматически при первом выполнении команды `/start`.
* **Уникальный тег:** Каждому профилю генерируется случайный идентификатор вида `#XXXXXXX`.
* **Отслеживание активности:** Логирует список ботов сети, в которых играл пользователь (`active_bots`).
* **Кастомизация:** Поддержка установки описания профиля (`/bio`) с ограничением до 200 символов.

## 🤖 Команды бота

### 👤 Пользовательские команды
- `/start` — регистрация и запуск главного меню
- `/help` — просмотр списка доступных команд
- `/id_profile` — открыть карточку глобального аккаунта Openbot AI ID
- `/game_stop` — принудительно завершить текущую игру
- `/sell_emoji [эмодзи] [цена]` — выставить эмодзи из инвентаря на аукцион
- `/bio [текст]` — изменить информацию «О себе» в Openbot AI ID
- `/feedback [текст]` — отправить сообщение или багрепорт разработчикам

### 🛠 Административные команды
- `/ban @username [причина]` — забанить пользователя в боте
- `/unban @username` — разбанить пользователя в боте
- `/get_status @username [роль]` — изменить статус игрока (`developer`, `tester`, `coder`, `admin`, `user`)
- `/give_coins @username [сумма]` — выдать монеты игроку
- `/take_coins @username [сумма]` — забрать монеты у игрока
- `/level_up @username [уровень]` — установить уровень игрока
- `/gift @username [эмодзи]` — подарить предмет в инвентарь игроку
- `/sendall [текст]` — выполнить рассылку сообщения всем пользователям
- `/MODE_true` / `/MODE_false` — включение/выключение режима тех. работ
- `/id_ban @username` — выдать глобальный бан ID во всей сети
- `/id_unban @username` — снять глобальный бан ID
- `/id_freeze @username` — заморозить global ID
- `/id_unfreeze @username` — разморозить global ID
