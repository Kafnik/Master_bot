Telegram-бот на Python (**pyTelegramBotAPI**) с играми, экономикой, коллекцией эмодзи, рынком между игроками и хэллоуинским обновлением. Часть сети ботов **Openbot.Ai**: права, статусы и баны берутся из общего аккаунта **OpenBot ID**.

## ✨ Возможности

### 🎮 Игры
| Игра | Описание |
|---|---|
| 🔮 Пророчество Ведьмы | угадай загаданное число |
| 🎃 Тыквы vs 💀 Черепа | крестики-нолики против бота |
| ⚰️ Битва с Призраком | пошаговый бой: ⚔️ атака, 🛡️ щит, 🧪 зелье |
| 🍬 Сладость или Пакость | игра на удачу |
| 🪦 Раскопки на Кладбище | игра на удачу |
| 🔐 Взлом замка | подбор кода по подсказкам |
| 💸 Бизнесмен | кликер: клик за монеты, недвижимость, магазин улучшений |
| 🛒 Торговец на базаре | покупай и продавай товары, лови выгодную цену |

За победы игроки получают монеты и опыт, иногда выпадает 🗝️ **Жуткий ключ**. Любую игру можно остановить командой `/game_stop`.

### 🗝️ Жуткие ключи и сундук
- Ключи выпадают за игры (шанс задаётся константой `SPOOKY_KEY_DROP_CHANCE`) и покупаются за ⭐ Stars.
- За 1 ключ **Жуткий сундук** выдаёт случайное эмодзи шести редкостей (👻 Обычная → 👁️ Легендарная). Дубликат превращается в монеты.
- Если выдача награды не удалась, ключ возвращается.

### 📦 Кейсы
8 кейсов с разными наградами (монеты, XP, эмодзи, ключи): 📦 Деревянный, 🥈 Серебряный, 🥇 Золотой, 💎 Алмазный, 🔥 Огненный, 🌌 Космический, 👑 Королевский, 🕳️ Кейс Пустоты. Кейсы покупаются за монеты или ключи, открываются из инвентаря кейсов; в окне кейсов виден баланс.

### 😎 Коллекция эмодзи
- более 200 эмодзи семи редкостей: ⚪ Обычная, 🟢 Необычная, 🔵 Редкая, 💠 Очень редкая, 🟣 Эпическая, 🟠 Легендарная, 🔴 Мифическая;
- инвентарь с постраничным просмотром и кружками редкости, карточка эмодзи: надеть на профиль, продать боту, выставить на рынок;
- проданное или выставленное на рынок последнее эмодзи автоматически снимается с профиля.

### 🏪 Рынок (аукцион)
Игроки продают друг другу эмодзи за монеты. На своём лоте вместо «Купить» стоит «Снять», раздел «📦 Мои лоты» показывает все выставленные предметы, продавцу приходит уведомление о продаже. Команда `/sell_emoji [эмодзи] [цена]` выставляет лот прямо из чата.

### 🏆 Титулы и профиль
- обычные титулы профиля и **хэллоуинские титулы** (от «🎃 Тыквенный магнат» до «🦇 Легенда Хэллоуина»), покупаются за монеты;
- профиль с уровнем, XP, монетами, титулом и надетым эмодзи;
- глобальный аккаунт `/id_profile` с био (`/bio`), статусом и списком ботов сети;
- два режима интерфейса: **inline-кнопки** или **reply-клавиатура** (переключается в настройках, бот понимает, какая клавиатура активна).

### ⭐ Telegram Stars
Магазин Stars: 10 000 000 монет, 5 Жутких ключей, прокачка до 20 уровня. Возврат платежа командой `/refund` (для разработчиков).

## 🤖 Команды

**Для всех**

| Команда | Что делает |
|---|---|
| `/start` | запуск бота |

**Для команды (developer / tester / admin / owner)**

| Команда | Что делает |
|---|---|

| `/give_coins`, `/take_coins` | выдать и забрать монеты |

| `/level_up` | изменить уровень игрока |

| `/sendall` | рассылка всем игрокам |
| `/MODE_true`, `/MODE_false` | включить и выключить тех. обслуживание |
| `/refund` | вернуть платёж в Stars |

## 🔐 Права и безопасность

- Статусы OpenBot ID: `owner` · `developer` · `admin` · `moderator` · `tester` · `user` · `frozen` · `banned`.
- Права проверяются через модуль `openbot_id` (функция `check_access(user_id, статусы, уровень)`).
- **Owner** может банить кого угодно; остальные не могут банить защищённые роли.
- **Тех. обслуживание**: флаг `maintenance` хранится в базе (`0` / `1`). Пока он включён, бот отвечает только команде, остальным показывает «Ведутся технические работы». Проверка стоит в одном месте (middleware).
- Глобально забаненные и замороженные аккаунты не могут пользоваться ботом.
- Ошибки бота (traceback) приходят в чат разработчика (`DEVELOPER_CHAT_ID`).
- `/gift` принимает только настоящие эмодзи, цифры и текст отклоняются.

## 🗂 Структура проекта

```
master_bot/
├── Master_bot.1.6.py      # основной код бота
├── openbot_id.py          # общий аккаунт и права (OpenBot ID)
└── halloween_db.py        # отдельная база хэллоуинского события
```

Базы создаются автоматически при первом запуске:

| Файл | Что хранит |
|---|---|
| `Master_bot.1.6.db` | игроки, инвентарь эмодзи, рынок, недвижимость, активные игры |
| `Halloween_event.db` | Жуткие ключи, кейсы игроков, купленные титулы, журнал событий |
| `openbot_id.db` | глобальные аккаунты сети |

**Отдельная база события.** Все изменения в `Halloween_event.db` проходят только через `halloween_db.py`: потокобезопасно, атомарно, с журналом (кто, когда, что и на сколько изменил). При первом запуске модуль один раз переносит старые данные из основной базы (основная база только читается, повторный перенос ничего не дублирует).

## 🚀 Установка и запуск

Скачивает с Realeses или вот так:
```bash
git clone <адрес репозитория>
cd master_bot
pip install pyTelegramBotAPI
python Master_bot.1.6.py
```

Перед запуском в `Master_bot.1.6.py` задай:
- `TOKEN` — токен бота от [@BotFather](https://t.me/BotFather);
- `DEVELOPER_CHAT_ID` — твой Telegram ID (сюда приходят отзывы и логи ошибок).

Требования: Python 3.9+, `pyTelegramBotAPI`.

## 🌐 Сеть Openbot.Ai

Master Bot работает вместе с **Random Bot**: общий аккаунт OpenBot ID, общие статусы и глобальные баны. У каждого бота своя основная база и своя база хэллоуинского события, поэтому они не конфликтуют.
